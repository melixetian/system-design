# Практика

Начнём с сервиса уведомлений, затем разберём резервирование складских остатков и сбор телеметрии от парка роботов. Завершим пробными интервью с дополнительными требованиями по ходу обсуждения.

[Бронирование билетов на концерт](concert-ticket-booking/) — 500 000 пользователей на старте продажи, 10 000 мест, максимум один билет на человека и десять минут на оплату. Разберём после задачи о складских резервах.

Для каждой задачи заведём отдельную папку в `practice/`. Условие будем хранить в `README.md`, решение — в `solution.md` рядом с ним. Диаграммы можно добавлять прямо в Markdown через Mermaid или прикладывать как изображения. Код можно вставлять небольшими фрагментами в решение или хранить отдельными файлами рядом.

Для разбора можно прислать ссылку на файл или pull request с решением.
